### ~~[auto-tab-grouper](./extensions/auto-tab-grouper)~~ [Deprecated]

> [!WARNING]
> This extension has side effects: it automatically saves the current window's groups when the browser is closed, and these "saved groups" cannot be accessed or cleared via scripts. In reality, these groups are intended to be temporary, but since this behavior cannot currently be changed, the extension is now deprecated; please use [auto-tab-arranger](#auto-tab-arranger) instead.
